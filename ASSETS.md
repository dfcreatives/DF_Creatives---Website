# Image sources

Stock photographs downloaded from Unsplash image delivery URLs as editable illustrative assets. They are not presented as actual DF Creatives clients, projects, or personnel.

- `public/images/studio.jpg`: https://images.unsplash.com/photo-1516035069371-29a1b244cc32 — camera photograph used in the hero and videography service.
- `public/images/team.jpg`: https://images.unsplash.com/photo-1522071820081-009f0129c71c — collaboration photograph used on about/culture sections.
- `public/images/event.jpg`: https://images.unsplash.com/photo-1531058020387-3be344556be6 — event photograph, included only in an unpublished sample project.

`public/images/df-creatives-logo.png` is the logo supplied by the user. The website frames this original square artwork with CSS and uses it for the favicon. The logo remains configurable through Site Settings.

The fallback wordmark, typographic poster, and graphic shapes are generated directly in SVG/HTML/CSS. Icons come from Lucide (ISC license). Dependencies retain their own license files.

Typography uses the Poppins family, self-hosted through `@fontsource/poppins` (SIL Open Font License).
